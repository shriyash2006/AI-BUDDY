# AI BUDDY by Millionminds

Frontend prototype MVP for an AI-powered Talent-as-a-Service platform connecting students, startups, and mentors.

## Stack

- Next.js 15 App Router
- TypeScript
- Tailwind CSS
- ShadCN-style UI primitives
- Framer Motion

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
